How to send photos and videos without compression

To send a photo or video in Telegram without compression, send it as a file instead of as a photo. In Telegram's iPhone app, open the attachment menu, switch to File and tap Select from Gallery. The app's own tip describes this option as a way to share uncompressed media from your camera roll.

Steps in the iPhone app

  1. Open the chat, group or channel you want to send to.
  2. Tap the attachment button next to the message field.
  3. In the menu that opens, switch from Gallery to File.
  4. Tap Select from Gallery and pick the photos or videos.
  5. Send them. They arrive as files, not as photos.

Another way, from the gallery

If you have already picked photos in the Gallery part of the attachment menu, open the ⋯ menu at the top of the picker and choose Send as File (or Send as Files for several). The result is the same: the media goes as files.

What changes when you send a file

  • The original is kept. The file that arrives is the file you picked, at its full quality, instead of a converted copy.
  • It looks different in the chat. The message shows a file rather than a photo or a video player. Whoever opens it gets the original.
  • It is bigger. An original is larger than a compressed copy, so it takes longer to send and to download, and it uses more space on any phone that downloads it.
  • The size limit still applies. Each file can be up to 2 GB on a free account and 4 GB with Premium. See the Telegram file size limit.

Videos and the Quality setting

When you send a video the normal way, the iPhone app opens it with a Quality setting, with steps from Very Low to Very High, and converts the video before it is sent. That is useful when you want a smaller file. When you want the video exactly as it was recorded, send it as a file with the steps above, and the conversion is skipped.

If the original video is over the limit, sending it as a file will not work. Then you need a smaller version first: see how to make a video smaller than 2 GB.

Good habits

  • Decide per chat. For a quick look, a normal photo is fine. For anything you want to keep, send the file.
  • Add a caption when you send, so you can search for it later. See how to organise files in Telegram.
  • Keep your originals on your phone or computer as well. Telegram is a messaging service, and its cloud chats are not end-to-end encrypted.

These steps describe Telegram's iPhone app. In Telegram's other apps the buttons can have different names.

How Cloud Shelves helps

Cloud Shelves sends photos as files by default, so Telegram keeps the original quality, and you can change that in the app's Sending settings. You pick a shelf for each batch, and the app adds the shelf and the month to every caption as hashtags, so the files stay easy to find later.
