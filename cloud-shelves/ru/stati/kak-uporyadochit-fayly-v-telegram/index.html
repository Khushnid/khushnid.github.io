Как упорядочить файлы в Telegram

Чтобы файлы в Telegram были в порядке, складывайте их в один чат только для файлов, добавляйте к каждому подпись с несколькими хештегами, а потом находите их через поиск по чату и вкладки с общими медиа. Папки чатов в Telegram группируют целые чаты, а не файлы, поэтому внутри чата сортировкой занимаются подписи.

  1. Выберите один чат для своих файлов.
  2. Пишите подпись с хештегами к каждому отправляемому файлу.
  3. Находите файлы через поиск по чату или нажатием на хештег.
  4. Просматривайте файлы по типам во вкладках с общими медиа чата.

1. Выберите один чат для своих файлов

Если смешивать файлы с чатами, где вы общаетесь с людьми, их потом трудно найти. Выберите одно место:

  • «Избранное» — чат с самим собой, который есть у каждого аккаунта, или
  • канал, в котором есть только вы: в нём файлы хранятся отдельно от всего остального, что вы сохраняете.

Оба варианта работают на бесплатном аккаунте. Их сравнение — в статье «Избранное» или свой канал.

2. Подписывайте каждый файл

Подпись — это текст, который отправляется вместе с фото, видео или файлом. На бесплатном аккаунте она может быть до 1024 символов, а с Telegram Premium — до 4096. Хорошая подпись короткая и единообразная:

  • что это, в нескольких словах («скан паспорта», «договор аренды»);
  • один-два хештега по теме, например #документы или #семья;
  • хештег для времени, например год и месяц.

Выберите хештеги один раз и используйте их повторно. #чек и #чеки — это два разных тега для поиска. Если забыли подпись, Telegram позволяет изменить её после отправки: когда вы редактируете сообщение с файлом, приложение для iPhone предлагает изменить подпись.

3. Ищите по чату и нажимайте на хештеги

Откройте чат и воспользуйтесь поиском по этому чату, чтобы найти слова из подписей. В документации Telegram для разработчиков сказано, что нажатие на хештег в чате запускает поиск этого хештега в том же чате, поэтому тег работает как фильтр: нажмите #документы, и вы увидите все файлы с этим тегом. FAQ Telegram подтверждает, что хештеги поддерживаются.

4. Просматривайте вкладки с общими медиа

Откройте профиль чата, чтобы увидеть его общие медиа. В приложении для iPhone там есть вкладки для медиа, файлов, ссылок, голосовых сообщений, аудио и GIF. Фото и видео, отправленные обычным способом, попадают на вкладку медиа, а документы — на вкладку файлов.

У глобального поиска Telegram тоже есть фильтры, например по медиа, ссылкам, файлам, музыке и голосовым сообщениям, когда вы ищете по всем чатам сразу.

Небольшие привычки, которые помогают

  • Отправляйте фото как файлы, если нужно оригинальное качество. См. как отправить без сжатия.
  • Закрепите сообщение, которое нужно чаще всего, например список ваших хештегов.
  • Напишите описание канала, если пользуетесь каналом, чтобы помнить, что в нём должно лежать.
  • Не полагайтесь на теги Premium. По документации Telegram для разработчиков, теги в «Избранном» — функция Telegram Premium. Хештеги работают в любом аккаунте.

Как помогает Cloud Shelves

Cloud Shelves сортирует файлы на вашем телефоне. Вы раскладываете файлы по полкам (готовым полкам для документов, учёбы, семьи, работы и видео или своим), а приложение показывает их по полкам и по месяцам, с поиском по названию. Оно также записывает полку и месяц в каждую подпись в виде хештегов, поэтому те же файлы легко найти и в приложениях самого Telegram. Когда вы переименовываете полку или перемещаете файл, подписи обновляются.
